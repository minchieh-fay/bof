# bof

币安 USDⓈ-M 合约实盘买入服务。只提交 GTX 限价买单。平仓、止盈和止损由人工操作。

## 启动

需要 Go 1.23 或以上版本。编辑 `config.yaml`，将 API Key 和 Secret 分别写入 `keyfile` 指定文件的前两行。持仓模式使用 `hedge`（双向）或 `one_way`（单向），并与账户设置一致。启动时会撤销账户中客户端订单号以 `bof_` 开头的遗留挂单，同一账户运行一个实例。

```sh
go build -o bof .
./bof -config config.yaml
```

默认使用 20 根已收盘的 30 分钟 K 线和 2 倍标准差计算布林下轨。按最近 7 根已收盘的现货日 K 线的 USDT 成交额排名，默认仅允许排名前 80% 的合约买入。市场清单每小时刷新一次，现货成交额按交易对逐小时轮转更新。
